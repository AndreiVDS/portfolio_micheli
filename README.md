# Portfolio — Micheli Raasch

A personal portfolio site **built for a client**, Micheli Jaqueline Sauner Raasch, an
education professional.

**Live:** <https://portfolio-micheli-jy3m.vercel.app>

## Sections

- **Profile** — name, role, quick links.
- **About** — experience and education.
- **Skills** — hard skills (educational planning, IT, well-being games, interpersonal) and
  soft skills.
- **Projects** — three case studies (Bazar do Bem, LIVE!RUN, Arena Jaraguá) with a video.
- **Contact** — direct links.

## Stack

`HTML` · `CSS` (with a dedicated `mediaqueries.css` for responsiveness) · `Vanilla JavaScript`
(hamburger menu) · deployed on Vercel

## Running

Static site — open `portifolio_micheli/index.html` or serve the folder with `npx serve`.
